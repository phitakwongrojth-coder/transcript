แปลภาษาแบบ real time

อีเมล (ไม่บังคับ) — ใส่แล้วโควตาแปลฟรีเพิ่มจาก 5,000 เป็น 50,000 ตัวอักษร/วัน (ประมาณ 1 ชม. lecture) · เก็บไว้ในเครื่องนี้เท่านั้น และส่งไปกับคำขอแปลที่ MyMemory

คำแปลทำโดยบริการแปลอัตโนมัติ MyMemory (ข้อความจะถูกส่งไปแปลบนเซิร์ฟเวอร์ของเขา) — บน Chrome คอมพิวเตอร์จะแปลในเครื่องแทน · คุณภาพพอเข้าใจใจความ ศัพท์แพทย์อาจเพี้ยน ให้ Copy ไปให้ Claude แปล/เรียบเรียงอีกรอบสำหรับโน้ตจริง

แก้ศัพท์อัตโนมัติ (ศัพท์แพทย์ที่ระบบมักฟังผิด)

บรรทัดละ 1 คู่ รูปแบบ คำที่ได้ยินผิด => คำที่ถูก · ไม่สนตัวพิมพ์เล็ก/ใหญ่ · ขึ้นต้นด้วย # = comment

วิธีใช้ / แก้ปัญหา

  1. iPhone: เปิดหน้านี้ใน Safari แล้วกด Allow ไมโครโฟน
  2. ต้องเปิด Dictation: Settings → General → Keyboard → Enable Dictation
  3. ถ้าไมค์ถูกบล็อก: Settings → Apps → Safari → Microphone → Allow (หรือแตะ "aA" บนแถบที่อยู่ → Website Settings)
  4. อย่าล็อกหน้าจอหรือสลับแอประหว่างอัด — iOS จะหยุดฟัง (แอปพยายามต่อให้อัตโนมัติเมื่อกลับมา)
  5. ระบบหยุดฟังเองเป็นระยะ แอปจะเริ่มฟังใหม่อัตโนมัติ อาจหลุดคำ 1–2 คำตรงรอยต่อ
  6. วางโทรศัพท์ใกล้ผู้บรรยาย/ลำโพง จะแม่นขึ้นมาก
  7. ภาษาจีน: ถ้าเลือกแล้วไม่ถอดเสียง ให้เพิ่มคีย์บอร์ดจีนที่ Settings → General → Keyboard → Keyboards → Add New Keyboard → Chinese (Simplified) แล้วลองใหม่
  8. แอปเปิดได้แม้ไม่มีเน็ต หลังจากเคยเปิดครั้งแรกแล้ว (แต่การถอดเสียงอาจยังต้องใช้เน็ต)
